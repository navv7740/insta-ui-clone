# INSTAGRAM UI CLONE

A front-end social media dashboard UI built with plain HTML, CSS, and JavaScript. Inspired by Instagram's feed layout.

## Features

- Scrollable feed with stories, likes, saves, and follow buttons
- Notification panel and image modal
- Sidebar popups (Messages, Saved, Settings, Logout)
- Responsive layout

## Files

- `index.html` — main dashboard
- `profile.html` — profile page
- `style.css` — styling
- `script.js` — interactivity

## Run it

Just open `index.html` in your browser. No install, no build step.

## Built With

HTML, CSS, JavaScript, Font Awesome, Google Fonts (Poppins)

## Note

Front-end UI clone for practice — no backend, actions are simulated with placeholder popups.
